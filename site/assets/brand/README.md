# Rust logo files

These files are the official Rust logo artwork from `rust-lang/rust-artwork`, downloaded unmodified from `logo/` on the `main` branch.

| File | Used for |
| --- | --- |
| `rust-logo-single-path.svg` | Header mark, favicon (dark logo on light grounds) |
| `rust-logo-white-outline.svg` | Manifest and footer (for dark and rust grounds) |
| `rust-logo-gear-only-single-path.svg` | Kept for reference; not used on the page |
