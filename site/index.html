01 · Install

Start with the source. Apply only what you review.

Install the package in your project, inspect the proposed file changes, then apply and verify the complete skill suite. The default is a dry run; installation is an explicit action.

npm path

Node.js 18+ and Python 3. The npm package bundles the installer and all five skills. No framework or frontend build step is required.

Clone path

Git and Python 3. Run the installer from a clone of the repository.

Supported agent

One of the coding agents listed under Agents, or the Claude Code plugin commands shown beside this panel.

Read the installation guide ↗

Terminal · project root npm
$ npm i rustacean-skills
$ npx rustacean-skills --list
$ npx rustacean-skills --agent codex --project-root .

Dry run: prints the plan and writes nothing.

$ npx rustacean-skills --agent codex --project-root . --apply

Writes the files, then verifies content hashes and peer links.

Replace codex with your agent ID.

Claude Code plugin · alternative

Terminal · Claude Code plugin
$ claude plugin marketplace add jelome265/Rustacean
$ claude plugin install rustacean@rustacean
Requires a Claude Code version with claude plugin commands.
02 · The skill suite

Five roles. One engineering standard.

The skills are designed to work together. They share rule IDs and references, and the installer rejects partial installations because the suite is intentionally connected.

RS-01Rulebook

Best practices

The normative rulebook: stable BP-* rule IDs, workspace lint policy, and explicit controls against risky Rust patterns.

Use for
Any Rust code written, reviewed, refactored or configured.
Role
The baseline the other four skills depend on.
RS-02Build

Implementation

A requirements-first procedure for turning an agreed design into maintainable Rust code.

Use for
Creating or extending crates, services, CLIs and libraries.
Role
Every rule it applies cites a BP-* rule.
RS-03Harden

Hardening

Security, resilience, observability, operational readiness, build discipline, and container controls.

Use for
Services that handle untrusted input, money, personal data or credentials.
Role
Builds on the rulebook baseline.
RS-04Inspect

Read-only audit

Evidence-based security and logic findings, each with severity, location at a pinned commit, reproduction, and remediation.

Use for
Security reviews, pre-launch reviews, and second opinions on Rust services.
Role
Never modifies code and never merges anything.
RS-05Control

Framework controls

An approved framework stack, prohibited patterns, and executable inventory checks to keep dependencies aligned with policy.

Approved stack
tokio, axum, tonic, sqlx, reqwest, serde, tracing with OpenTelemetry, clap, rustls.
Enforcement
Clippy disallowed-method and disallowed-type bans, plus route and client inventory tests.
03 · Method

Guidance is useful. Verification makes it accountable.

Rustacean combines written instructions with checks where automation can provide evidence. Skills guide agent behavior; they do not replace compilers, tests, CI, or human review.

01 · RULES

Stable references

Rules have identifiers that can be cited in implementation plans, reviews, and audit findings.

02 · POLICY

Lint as code

Workspace lints and tested gates turn selected prohibitions into build-time feedback.

03 · EVIDENCE

Checkable output

Installation hashes, peer-link checks, tests, and CI supply evidence instead of relying only on claims.

04 · BOUNDARIES

Review remains

Read the skills, examine proposed changes, and keep the normal review and release controls in place.

05 · Verify

File installation is not agent discovery.

After applying the plan, the installer checks content hashes and peer links. Then confirm that your agent actually lists the five Rustacean skills.

  1. Start a new session or restart the agent.
  2. List the skills in the agent and confirm all five appear.
  3. Check discovery separately for each agent you use.
Important. A successful installer run confirms that files are present and verified. It does not prove that the target agent loaded or followed them.
